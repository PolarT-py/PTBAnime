# PTBAnime

---

> [!WARNING]
> **PTBAnime Rework in Progress!**
> 
> The base App is not in proper working condition. It is still under heavy development and is NOT usable right now.

`PTBAnime` is an App made with QT6 in Python, for watching and tracking your Local Anime collection, integrated with AniList.

---

## Development

> Python Version: `>=3.11`

> #### Required Python Packages:
> 1. `PySide6`
> 2. `requests`
